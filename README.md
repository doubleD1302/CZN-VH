## 🌐 English: Notice for Publishers & Developers (Smilegate & Super Creative)

### 1. Project Overview
This repository (`CZN-VH`) hosts an **unofficial, fan-made Vietnamese localization patch** for *Chaos Zero Nightmare*. Its sole purpose is to help the Vietnamese player community understand the in-game story, dialogues, and user interface.

### 2. Technical Scope & Fair Play Compliance
We strictly respect the integrity and security of *Chaos Zero Nightmare*:
* **Text & UI Localization Only:** This project only translates localized text strings, subtitles, and UI descriptions into Vietnamese.
* **No Gameplay Modification:** It does **not** alter game mechanics, combat logic, character stats, client-server network packets, or memory processes.
* **No Unfair Advantage:** It contains no cheats, macros, automation scripts, or exploits of any kind.
* **No Redistributed Paid Assets:** This repository only provides localization files/scripts and does not distribute full game clients or paid proprietary content.

### 3. Non-Commercial Statement
This project is **100% free and non-commercial**, developed by fans for fans. We do not sell this patch, charge subscription fees, lock files behind paywalls, or run commercial advertisements.

### 4. Copyright & Takedown Policy
All intellectual property rights, trademarks, game assets, character names, and original texts of *Chaos Zero Nightmare* belong exclusively to **Super Creative** and **Smilegate** (Smilegate Megaport). 

We have proactively reached out to Smilegate Support regarding this community project. If Smilegate or Super Creative requests any modifications or the removal of this repository, we will comply **immediately and unconditionally**. 
* **Contact for Official Inquiries / Takedown:** Via GitHub Issues or project maintainers.

**CZN-VH** là dự án Việt hóa phi thương mại dành cho tựa game *Chaos Zero Nightmare*, được thực hiện với mục đích hỗ trợ cộng đồng người chơi tại Việt Nam trải nghiệm trọn vẹn cốt truyện và nắm bắt hệ thống kỹ năng, giao diện dễ dàng hơn.

* **Bản quyền:** Toàn bộ hình ảnh, âm thanh, cốt truyện và tài sản trí tuệ của trò chơi thuộc quyền sở hữu của **Super Creative** và **Smilegate**.
* **Lưu ý an toàn tài khoản:** Dù bản vá chỉ thay đổi ngôn ngữ hiển thị và không can thiệp vào dữ liệu trận đấu, mọi hành vi can thiệp vào tệp tin phía máy khách (client) khi chưa có sự tích hợp chính thức từ Nhà phát hành đều tiềm ẩn rủi ro từ hệ thống bảo mật tự động. Người dùng vui lòng cân nhắc và tự chịu trách nhiệm khi sử dụng.

### 3. Hướng dẫn cài đặt
Dự án cung cấp công cụ tự động cài đặt (không cần chép tệp thủ công):

* **Dành cho Windows (PC):**
  1. Tải công cụ cài đặt `CZN_VietHoa_Windows_launcher.exe` tại mục [Releases](https://github.com/doubleD1302/CZN-VH/releases).
  2. Khởi chạy công cụ và chọn thư mục cài game *(Mặc định: `C:\ProgramData\Smilegate\Games\ChaosZeroNightmare`)*.
  3. Bấm **Cài tiếng Việt** và khởi động game.

* **Dành cho Android:**
  1. Tải tệp `CNZ_VietHoa_Fanmade.apk` tại mục [Releases](https://github.com/doubleD1302/CZN-VH/releases).
  2. Cấp quyền qua **[Shizuku](https://shizuku.rikka.app/)**, mở ứng dụng và bấm **Cài tiếng Việt**.
  3. Khởi động game và trải nghiệm.

*(Để gỡ bản Việt hóa: Bấm "Khôi phục gốc" trong công cụ cài đặt hoặc sử dụng tính năng "Verify Integrity / Repair Game Files" trên STOVE Client).*
